# ⚡️ Rush

> [!IMPORTANT]
> This branch is for major refactoring. The latest stable release can be found in [**releases**](https://github.com/shreyashsaitwal/rush-cli/releases).

### Features

- 🔍 Gradle-based dependency management
- 🌎 Language support for Kotlin
- ⏳ Shorter compilation times

### Installation

> [!WARNING]
> The following instructions pertain to this branch only. A stable version will **not** be installed.

#### MacOS / Linux

```bash
curl https://raw.githubusercontent.com/shreyashsaitwal/rush-cli/tree/refactor/scripts/install.sh -fsSL | sh
```

#### Windows

```powershell
iwr https://raw.githubusercontent.com/shreyashsaitwal/rush-cli/tree/refactor/scripts/install.ps1 -useb | iex
```
