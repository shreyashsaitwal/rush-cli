# Rush documentation

Rush builds extensions for [MIT App Inventor](https://appinventor.mit.edu) from Java or
Kotlin sources. These pages cover everything from a first build to shipping libraries and
resources.

## Guides

1. [Getting started](getting-started.md): install Rush, create a project and import it
   into App Inventor.
2. [Writing extensions](writing-extensions.md): functions, properties, events, dropdowns
   and asynchronous blocks.
3. [Android manifest](manifest.md): permissions, activities, services and other manifest
   entries.
4. [Dependencies](dependencies.md): using Maven libraries and local JARs and AARs.
5. [Resources](resources.md): layouts, drawables, strings and colors.
6. [Building](building.md): what `rush build` produces, optimization, Java versions and
   the generated documentation.
7. [GitHub Actions](github-actions.md): building and releasing on GitHub.
8. [Migrating from Rush 1](migrating.md).
